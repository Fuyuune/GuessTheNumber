# Guess the Number

A small number-guessing game written in Python with a graphical user interface
based on `tkinter`.

## How to Play

The program randomly selects a number between 1 and 100. Enter your guess and
click **Calculate**. Use **Get Hint** to find out whether the secret number is
higher or lower than your guess.

## How to Run

Make sure Python 3 is installed, then start the game with:

```bash
python main.py
```
